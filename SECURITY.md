# Security Policy

## Supported versions

ShellSentry-AI is currently in early development. Security fixes are applied to the latest release only.

## Reporting a vulnerability

Do not include real malware samples, API keys, private source code, or other sensitive data in a public issue. Open a minimal issue requesting a private reporting channel, or use GitHub private vulnerability reporting when it is enabled for the repository.

## Analysis boundary

ShellSentry-AI performs static analysis and must never execute submitted samples. A model provider is contacted only when the user explicitly configures and enables model-assisted analysis.
